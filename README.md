## Selected Projects

### [WC 2026 Match Outcome Predictor](https://github.com/veselinkalinov/wc2026-predictor)

End-to-end machine-learning system for predicting international football match outcomes and simulating the 2026 World Cup.

- Processed data from **40,000+ international matches**
- Engineered **27 domain-specific features**, including Elo ratings, EWMA form, rolling goal statistics, ranking joins, travel indicators, rest days, and match importance
- Compared **8 model families** and selected a stacking ensemble by holdout log loss
- Implemented probability calibration, draw-risk surfacing, and neutral-venue symmetric prediction
- Built a **Flask REST API**, web dashboard, Monte Carlo simulator, automated retraining workflow, and model hot-reloading
- Containerized the application using **Docker Compose**
- Added automated tests with **pytest**

`Python` · `Scikit-learn` · `XGBoost` · `LightGBM` · `CatBoost` · `Flask` · `Docker` · `pytest`
