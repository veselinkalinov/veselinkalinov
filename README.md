## Projects

**Routiq** — Multi-agent intermodal travel planner for European routes

Orchestrates planning, retrieval, and route-comparison agents over a Qdrant
vector store. Stack: Python, FastAPI, React, Supabase, Qdrant, LLM APIs.
Deployed on Railway + Vercel.

**AI Prompt Optimization App** — Backend complete, frontend in progress

Scores prompts against quality heuristics and returns structured rewrites.
I built the RAG pipeline and FastAPI layer first, then moved to the Next.js
frontend. Stack: FastAPI, Supabase, Qdrant, Gemini API, Next.js.
