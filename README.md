## Featured Projects

### WC 2026 Match Outcome Predictor

**End-to-end machine learning project for football match outcome prediction.**

Repository: [github.com/veselinkalinov/wc2026-predictor](https://github.com/veselinkalinov/wc2026-predictor)

Built an end-to-end ML pipeline for predicting World Cup 2026 match outcomes.

Key work:

* Built a complete Python-based ML pipeline for football match prediction.
* Achieved **60.43% accuracy** on a held-out post-2023 test set.
* Engineered **27 features** from **40,000+ matches**, including custom Elo ratings, EWMA team form, rolling goal averages, and FIFA ranking integration.
* Compared **8 classifiers**, including LightGBM, CatBoost, XGBoost, and a Stacking Ensemble.
* Built a Flask REST API with **10 endpoints** and an interactive web dashboard.
* Containerised the system with Docker Compose.
* Implemented a Monte Carlo simulator for full 48-team bracket simulations with dynamic Elo and form updates.

Tech stack:
`Python` · `Pandas` · `NumPy` · `Scikit-learn` · `XGBoost` · `LightGBM` · `CatBoost` · `Flask` · `Docker`
